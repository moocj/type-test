# type-test

a simple, minimal typing test, with simple pastel colours and no frameworks.

**stack:** fastapi + sqlmodel + sqlite · vanilla js (es modules) · chart.js · pytest

## run it

```bash
python -m venv .venv
source .venv/Scripts/activate        # windows git bash (powershell: .venv\Scripts\Activate.ps1)
pip install -r requirements.txt
python -m uvicorn app.main:app --reload   # run from this folder
```
